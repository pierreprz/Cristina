# Cristina

Carte d'anniversaire animée pour les 40 ans de Cristina (en anglais) : musique salsa,
confettis, balade en forêt, gâteau à souffler et carte postale.

- `index.html` : la carte, une seule page autonome (rien à installer).
- `preview.png` : la vignette affichée quand on partage le lien.

En ligne avec GitHub Pages : https://pierreprz.github.io/Cristina/
